# Claude Quick Snap

Tray app for Windows. Snap a screenshot (full screen or a dragged region), type a question, send it straight to Claude's API, see the answer.

## Setup
1. Download `ClaudeQuickSnap.exe` from the latest GitHub Actions build (Actions tab → latest run → Artifacts).
2. Run it. It sits in the system tray.
3. Right-click tray icon → "Set API Key" → paste your Anthropic API key (get one at console.anthropic.com/settings/keys).

## Use
- Left-click tray icon or right-click → "Snap Region" → drag a box around any part of the screen.
- Or "Snap Full Screen" for the whole thing.
- Type a question (optional) and hit Send.
